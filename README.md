# Sistema de Gerenciamento de Produtos

Sistema completo de gerenciamento de produtos construído com Vue.js 3 e Flask.

## Tecnologias

- **Frontend**: Vue.js 3, Vue Router, Pinia, Axios
- **Backend**: Flask, SQLAlchemy, JWT
- **Estilização**: CSS Moderno com variáveis e temas

## Instalação

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd backend
pip install -r requirements.txt
python app.py
```

## Funcionalidades

- Sistema de autenticação completo
- CRUD de produtos
- Dashboard com métricas e gráficos
- Tema claro/escuro
- Interface responsiva
- Filtros e busca avançada
